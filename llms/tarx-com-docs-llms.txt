# TARX Docs

TARX is an AI work system for controlled context, tools, memory, evidence, and runtime choice.

## Core concepts

- Spaces hold context for a body of work.
- Chat does work using Space context.
- Comms handles people, drafts, handoffs, and approvals.
- Computer is the user's local machine and tools.
- Control governs account, memory, Vault, apps, approvals, billing, and capacity.
- Evidence shows what TARX used, changed, or decided.
- Supercomputer is optional hosted capacity, not the default product path.

## Capability status labels

- Available now: the surface exists and can be used or reviewed today.
- Pilot-ready: suitable for controlled evaluation or early account access.
- Enterprise evaluation: requires enterprise review, agreement, or implementation planning.
- Government evaluation: requires public-sector review, approval path, or implementation planning.
- Roadmap: directional, not available for use.
